# Mortal game design

Mortal begins at birth. Its journal groups major events, decisions, and actual stat changes by age. Each life begins in one of three fictional cities in Veyra. The character's household, natural talent, and other generated traits create different starting conditions.

## Phase 1 experience

- Random Life rolls a name, gender, hometown, household background, optional talent, attributes, and parents. Custom Life lets the player set the same profile fields and choose a birth year.
- The journal shows the character's age, city, education, balance, and four core attributes. Life Statistics shows the remaining attributes and background.
- Age Up advances one year. Early-life milestones introduce the player to choices. Optional events use context such as city, age, attributes, family circumstances, and talent. Some decisions return as consequences years later.
- The five bottom actions lead to Career, Relationships, Assets, and Activities, or advance the simulation directly. Phase 1 includes school progression and study, biographies and conversations for parents, a bank ledger, and a few activities.
- Completed lives retain their journal and a summary with age, cause of death, education, balance, and family.

The native visual system uses white and soft-blue surfaces, subtle dividers, pastel stat meters, and system emoji. Game copy starts in English. Common strings live in an English dictionary so more UI can move to translation keys as Bahasa Indonesia support is added.
